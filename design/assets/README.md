# Gold visual assets

Generated with the built-in imagegen tool for this prototype. These are symbolic illustrations, not verified chart calculations, consultant photos or client photos. Original PNGs and pixel-preserving lossless WebP encodings are retained. WebP images are embedded in `ui-prototype.html`; it has no runtime asset-server dependency.

- `hero-gold.png` / `hero-gold.webp`: reference-inspired gold temple landscape and celestial wheel.
- `vastu.png` / `vastu.webp`: Indian home and directional compass.
- `kundali.png` / `kundali.webp`: symbolic diamond-grid chart.
- `birth-chart.png` / `birth-chart.webp`: symbolic circular chart.

## Final icon prompts

Each was generated separately with this exact prompt structure:

> Create one polished compact UI illustration asset. [SUBJECT] Style: premium flat illustration with subtle dimensional depth, restrained fine charcoal line work and antique gold #C6A15B accents, ivory #FAF9F5 background. Centered object occupying 75% of square canvas; generous clean margin, readable at 64px, cohesive Indian astrology product icon. No gradients outside the illustration, no text, no logos, no watermark, no extra objects. Intended as an actual image icon in a web prototype.

Subjects:

- Vastu: A small traditional Indian home seen from a gentle isometric angle, with a clear compass ring and cardinal-direction tick marks beneath it. No letters. Architectural Vastu guidance icon.
- Kundali: A traditional North Indian diamond-grid kundali chart on a square ivory parchment tile, with gold framing, small gold celestial dots, no text, no numbers, no actual astrological positions. Symbolic Kundali icon.
- Birth chart: A circular astrological birth-chart wheel with twelve clear radial segments and a small sun at the center, on ivory, with subtle celestial gold dots. No zodiac characters, no letters, no numbers. Symbolic birth chart icon.

## Final hero prompt

The user's supplied gold hero screenshot was used as a style reference.

> Use the reference only as visual style guidance. Create a wide 3:1 website HERO BACKGROUND ART only, no text, no letters, no buttons, no logos, no rounded outer frame. Premium warm Indian Vedic landscape: antique gold #C6A15B and pale warm parchment #EAD8AE atmosphere, very subtle temple silhouettes confined to far lower right, softly layered hills at bottom right, fine low-contrast ivory celestial zodiac wheel high on right.
